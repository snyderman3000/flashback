Fixes from the first round of testing on a real Miyoo Mini Plus.

- **Showing the answer works with A.** The screen didn't redraw once the flip animation ended, so the card stayed blank and a second A graded a card you hadn't seen.
- **Decks no longer crash on open.** Templates using `{{clickable::Tags}}` (common in AnkiHub-era shared decks) crashed the app. A card that can't be rendered now shows a message instead of closing Flashback, and a deck that can't be unpacked shows an error in the catalog.
- **JavaScript-built note types** such as "Cloze Overlapping" showed blank cards. Flashback now shows their cloze text directly.
- **Readable maths.** MathJax like `\(\frac{q_1 q_2}{4\pi\epsilon_0 r^2}\)` is shown as `(q₁ q₂)/(4πε₀ r²)` instead of raw TeX.
- Lines no longer break where there's no space (e.g. between `[` and a cloze).
- Messages ("toasts") no longer linger on screen.

Install over the top of v0.1.0; progress and settings are kept.
